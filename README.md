# XizmatGo

Мобильный marketplace услуг для Узбекистана. Текущая версия — интерфейс MVP; серверные функции подключаются поэтапно.

## Возможности текущей демо-версии
- Адаптивная главная страница.
- Каталог категорий и поиск.
- Формы заявки клиента и регистрации специалиста (пока демонстрационные).
- Доступность с телефона и компьютера.

## Локальный запуск
Откройте `index.html` в браузере. Для локального сервера можно использовать:
```bash
python -m http.server 8080
```
Затем откройте `http://localhost:8080`.

## Следующие этапы
1. Подключить отдельный проект Supabase.
2. Реализовать вход по номеру телефона и SMS OTP.
3. Подключить хранение профилей, услуг и заявок с Row Level Security.
4. Добавить кабинеты клиента и специалиста, загрузку фотографий, статусы заявок.
5. Добавить модерацию и админ-панель.
6. Подготовить деплой, домен, тестирование и затем Android-приложение.

## Безопасность
- Не добавляйте service-role ключ Supabase в браузер или репозиторий.
- Используйте только publishable/anon key на клиенте и включайте RLS для таблиц.
- Правила регистрации и допустимые категории услуг нужно сверить с действующими требованиями законодательства Узбекистана.

Проект независим от ADAMARKET и не должен использовать его базу данных или секреты.
